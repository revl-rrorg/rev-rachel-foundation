# Contributing

Read AGENTS.md before editing.

## Branches

Work on staging. Do not push directly to master. Production release requires explicit owner approval. Keep review prototypes separate from the production index.html until integration is requested.

## Changes

Coordinate ownership before editing. Start from the latest staging commit. Make focused changes tied to the requested task and preserve other contributors' edits. Use pull requests for review where appropriate.

## Handoffs

Include the requested change, affected files, commit or pull-request link, preview version, verification results, unresolved decisions, and next owner. Distinguish proposed changes from approved decisions.

## Verification

Check desktop and mobile layouts, image loading, navigation, and affected interactive controls. Verify section counts after structural edits. A repository source link is not a deployed browser preview.

## Privacy

Keep private conversations, internal coordination links, credentials, and personal contact details out of this public repository.
